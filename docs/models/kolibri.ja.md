# Kolibri 1

[README.ja.md](../../README.ja.md) に戻る

**Kolibri 1**：Aleph Alpha のモデル。19,200 個のエキスパートでできていて、英語と同じようにドイツ語も書けます。ファイルは 29〜48 GB で、小さいカードではほとんどが RAM に置かれます。5 つの層のうち 4 つは 513 トークンしかさかのぼりません。

## どのくらい速い？

[Flint 40B-A2.5B](flint.ja.md) と同じ方法で、31,676 トークンのプロンプトで測りました。

ワークステーションのカードには Q2_K の 19,200 個のエキスパートがすべて載ります（25.6 GiB）。31,676 トークンのプロンプトに 6.3〜6.4 秒で答え始め、その後は毎秒 129〜131 トークンで書きました。Q4_K_M と Q3_K_M はワークステーションでは動かしておらず、ノート PC ではどのサイズも動かしていません。

このモデルを追加したプルリクエストでは、ほかの PC で測っています。RTX 3060（12 GB）、RAM 24 GB の Windows では、Q2_K が短いチャットを毎秒 21 トークンで書き、32K のプロンプトを毎秒 698 トークンで読みました。Tesla V100（32 GB）1 枚では Q4_K_M が毎秒 91 トークンで書き、32K のプロンプトを毎秒 1,017 トークンで読み、2 枚では毎秒 2,179 トークンで読みました。

変換に付いている `kolibri1` パッチを当てた llama.cpp と比べました。英語とドイツ語のプロンプトに対する llama.cpp の貪欲な回答をなぞると、Q2_K がいちばん確率の高いトークンとして同じものを選んだのは、128 ステップのうちそれぞれ 120 と 126 でした。食い違ったステップでも、1 か所を除けば llama.cpp のトークンはこのエンジンの 2 番目か 3 番目の候補で、確率はほとんど同じでした。

## 必要なもの

| | |
| --- | --- |
| **グラフィックカード** | **NVIDIA** GeForce RTX 20 シリーズ以降のカード 1 枚、**VRAM 8 GB 以上**。エキスパートを載せる前に約 4 GB を使います。動かしたのは 12 GB のカード、32 GB の Tesla V100、32 GB の RTX 5090 です。 |
| **RAM** | 8 GB のカードと組み合わせる場合、Q4_K_M、Q2_K、Q3_K_M でそれぞれ約 **52、33、42 GB**（インストーラーの見積もり）。32 GB のカードなら Q2_K は約 10 GB、Q4_K_M は約 26 GB です。 |
| **ディスク** | モデルファイルに 29〜48 GB。 |
| **OS** | Linux または Windows 10 / 11 と、最新の NVIDIA ドライバー。 |

それ以外はインストーラーが用意します（[Qwen3.6-35B-A3B](qwen36.ja.md) と同じ）。AMD のカードではまだ試していません。テキストしか読めず、ドラフトモデルもないので、1 トークンずつ書きます。ライセンスは Apache 2.0 です。

## どのモデルを選べばいい

[Hob-forge](https://huggingface.co/Hob-forge/Kolibri-1-GGUF) の変換による 3 サイズです。8 GB のカードと組み合わせる場合、インストーラーは RAM 約 48 GB から Q4_K_M、それより少なければ Q2_K を選びます。カードが大きければ、どちらも必要な RAM は減ります。Q3_K_M は名前で指定します（`--model Q3_K_M`）。

| サイズ | 内容 | ダウンロード | 8 GB のカードと組む場合の RAM |
| --- | --- | ---: | ---: |
| **Q4_K_M** | 4 ビット。半分の層では down 射影が 6 ビット | 48 GB | 約 52 GB |
| **Q2_K** | 2 ビット。必要な RAM がいちばん少ない | 29 GB | 約 33 GB |
| **Q3_K_M** | 3 ビット | 38 GB | 約 42 GB |
